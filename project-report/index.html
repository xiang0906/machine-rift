END-TO-END SEQUENCES

兩條重要後端資料流

Transaction Boundary

防禦塔永久購買

  1. TowerController接收 towerId 與登入 Token
  2. AuthService驗證 Token 並取得目前玩家
  3. TowerService確認塔存在並鎖定玩家資料
  4. Repository檢查重複購買與永久金幣
  5. Transaction扣款、新增解鎖關聯並回傳餘額

遊戲結束與進度更新

  1. GameRecordController接收關卡、分數、勝敗與時間
  2. GameRecordService確認玩家已解鎖該關卡
  3. GameRecordRepository新增本局 GameRecord
  4. PlayerProgressService更新最佳分數、時間與完成次數
  5. Transaction勝利時發獎勵並解鎖下一關

SECURITY & ERROR BOUNDARY

安全與例外處理

玩家身分由 Bearer Token 決定，不接受前端指定其他 playerId。
敏感資料密碼使用 BCrypt；資料庫只保存 Token 的 SHA-256 雜湊。
DTO 邊界不將 passwordHash、sessionTokenHash 等 Entity 欄位回傳前端。
錯誤格式GlobalExceptionHandler 統一中文訊息及 HTTP 狀態碼。

BACKEND FUNCTION INDEX

後端 Function 全覽

依功能模組整理明確寫在程式中的方法；不重複列出 Lombok 產生的方法及 JpaRepository 基本 CRUD。

01

會員與登入

AuthController / AuthService
AuthController
  • register()接收註冊資料並建立玩家
  • login()驗證帳密並回傳 Token
  • me()取得目前登入玩家
  • logout()使目前 Token 失效
AuthService
  • register()檢查重複、加密密碼、初始化玩家
  • login()比對 BCrypt 密碼
  • requirePlayer()驗證 Bearer Token 與到期時間
  • logout()清除 Token 雜湊與到期時間
  • createSession()產生 30 天登入 Session
  • extractBearerToken()解析 Authorization Header
  • normalizeUsername()帳號去空白並轉小寫
  • hashToken()以 SHA-256 保存 Token 雜湊
PlayerRepository 自訂查詢
  • findByUsername()依登入帳號尋找玩家
  • findBySessionTokenHash()依 Token 雜湊尋找玩家
  • existsByUsername()檢查登入帳號重複
  • existsByPlayerNameIgnoreCase()不分大小寫檢查玩家名稱
02

玩家進度

PlayerController / PlayerProgressService
PlayerController
  • getPlayerProgress()回傳登入玩家完整進度
PlayerProgressService
  • initializePlayer()補齊預設值與起始解鎖
  • getProgress()組合金幣、關卡與塔解鎖
  • isStageUnlocked()確認玩家可進入關卡
  • recordGameResult()更新最佳戰績、獎勵與完成次數
  • isBetterResult()比較高分與同分較短時間
  • unlockNextStage()勝利後解鎖下一關
  • findFirstPlayableStage()尋找第一個完整可玩關卡
  • unlockStage()建立或更新關卡解鎖
  • unlockTower()建立玩家起始塔解鎖
進度 Repository 自訂查詢
  • findAllByPlayerPlayerIdOrderByStageStageIdAsc()取得玩家全部關卡進度
  • findByPlayerPlayerIdAndStageStageId()取得玩家單關進度
  • existsByPlayerPlayerIdAndStageStageIdAndUnlockedTrue()確認關卡已解鎖
